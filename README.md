# Калькулятор кода Murata MLCC

Автономный HTML-инструмент (один файл, без сборки и сервера) для разбора и сборки номеров (MPN) керамических SMD-конденсаторов Murata (GRM, GCM, GJM, GQM, KCM и др.) с проверкой по встроенной выгрузке каталога Murata.

**Открыть онлайн:** https://wadi-li.github.io/murata-mlcc-calculator/ — или скачать `index.html` и открыть в браузере (работает без интернета; интернет нужен только для онлайн-сверки и ссылок на магазины).

Пример: `GRM1885C1H221GA01D` → GRM, 0603 (1,6×0,8 мм), T = 0,8 мм, C0G, 50 В, 220 пФ, ±2 %, индивидуальный код A01, бумажная лента на катушке ø180 мм (4000 шт.).

## Возможности

- **Разбор кода** по полям с проверкой существования номера в каталоге Murata; при ошибке — подсказка похожих существующих номеров с подсветкой отличий и список допустимых кодов упаковки.
- **Подбор изделия из каталога** через восемь связанных выпадающих списков (серия, размер, толщина, ТКЕ, напряжение, ёмкость, допуск, индивидуальный код): показываются только реально существующие сочетания со счётчиками. Дополнительные фильтры: статус производства, применение, рабочее напряжение, максимальная температура.
- **Карточка изделия и оценка применимости:** статус (в производстве / NRND / планируется снятие / снято) с датами, запас по напряжению и температуре, предупреждение о DC-bias для диэлектриков класса 2, размеры с допусками, масса, варианты упаковки с количеством.
- **Онлайн-сверка** статуса с публичным API Murata (pim.murata.com).
- **Встроенная база:** 41 706 номеров MLCC SMD из каталога Murata (выгрузка от 25.10.2026).
- **Экспорт CSV** (разделитель `;`, UTF-8 с BOM): результат разбора и все найденные номера подбора (номер без кода упаковки и параметры).
- **Поиск по магазинам** полного кода и номера без кода упаковки: Murata, Chipfind, Чип и Дип, LCSC, Mouser Europe, ДКО Электронщик, КомпЭл, Контест, Озон.
- **Справочник кодов** серий, размеров, ТКЕ, напряжений, допусков и упаковок по листам Murata Part Numbering, дополненный кодами из реальных номеров каталога.
- Светлая тема по умолчанию, переключение на тёмную; адаптивная вёрстка для телефона.

## Ограничения

- Встроенная база — снимок каталога на дату выгрузки; актуальный статус проверяйте кнопкой «Проверить онлайн в Murata» или на сайте Murata.
- Для кодов напряжения серий на 250 В и выше (L*) данные карточек Murata и листа Part Numbering расходятся — ориентируйтесь на карточку изделия.
- Ссылки на Озон, КомпЭл и Mouser Europe не проверены автоматически (сайты ограничивают автоматические запросы).
